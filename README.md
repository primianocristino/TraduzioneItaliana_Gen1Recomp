# Traduzione Italiana per gen1recomp

Questa mod fornisce la traduzione in lingua italiana per **gen1recomp**, il progetto di decompilazione e ricompilazione nativa per i giochi della prima generazione Pokémon (attualmente supporta **Pokémon Versione Rossa** e **Pokémon Versione Blu**).

Puoi trovare il progetto originale e le istruzioni di configurazione su GitHub: [https://github.com/bryanthaboi/gen1recomp](https://github.com/bryanthaboi/gen1recomp).

## Come installare la mod

Per installare correttamente la traduzione, segui questi passaggi:

1. Scarica o compila **gen1recomp** dal [repository ufficiale GitHub](https://github.com/bryanthaboi/gen1recomp).
2. Posiziona il file della mod all'interno della cartella dedicata ai moduli, situata nel percorso:
   `...\gen1recomp\mods`
3. Avvia il programma e goditi l'esperienza di gioco in italiano!
